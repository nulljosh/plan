# Rules

Joshua's rules for picking classes. These come first: if a class breaks one, it isn't an option.

## Where
- **Langley only. No Surrey. No Richmond.** Home is Brookswood, Langley. KPU Langley and LECSS
  are a 5-minute drive or a 1-hour walk. Surrey and Richmond are not.
- **In class first.** Online is a fallback, only when there's no Langley in-person section and
  the class can't wait.
- **Online must be fully online.** If an online section has its exams or labs at Surrey or
  Richmond, it breaks the first rule.

## When
- **One class a day.** No back-to-back classes. KPU classes end at :50, and a 10-minute gap is
  too tight.

## How many
- **Fewer classes, better GPA.** SFU admits transfer students on their GPA, and GPA is an
  average. One strong class beats three rushed ones.
- Permanent disability: a 40% load counts as full-time for StudentAid BC, so 3 classes is plenty.

## What
- **Goal: SFU Computing Science.** Every class should help get there.
- Not doing KPU's BTech IT. Its INFO courses run only at Surrey.

## Checking a class
1. Langley campus? If not, is it fully online with nothing at Surrey or Richmond?
2. Does it share a day with another class, or sit right next to one?
3. Does it count toward SFU Computing Science? Check the BC Transfer Guide (bctransferguide.ca).

## What SFU Computing Science wants (checked Nov 27 2026)
Transfer entry, from [SFU's transfer page](https://www.sfu.ca/students/admission/admission-requirements/canadian-transfer/college-university.html):
- **24+ transferable credits.** With 9–23 credits, SFU uses high school marks instead, and then
  Pre-Calc 12 is required.
- **One math course:** MACM 101 or 201 (discrete math), MATH 150/151 (calculus I), 152, or 232/240.
- **One programming course:** CMPT 125 (or 126, 128, 135), 127, 225, 295, or 276.
- **One more** from either list.
- **GPA:** competitive. Past admits ranged from 2.50 to 3.50 depending on the program.
- **Quantitative skills:** 60% in a grade 11 or 12 math course, or a C- in a transferable math course.
- Pre-Calc 12 isn't an admission rule for transfer entry, **but it's the prerequisite for the math**:
  MACM 101 needs Pre-Calc 12 (or SFU MATH 100); MATH 151 needs Pre-Calc 12 with an A (or MATH 100
  with a B). So learn Pre-Calc somewhere that works, then take discrete math (least algebra).
- KPU's versions of these courses (MATH 1120, CPSC 1103/1204) run only at Surrey in Spring 2027.
  Check the BC Transfer Guide for a Langley or fully online version (e.g. TRU Open Learning COMP 1230,
  listed as matching SFU CMPT 125) before signing up.
