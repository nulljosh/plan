Plan · iOS blueprint

The plan, in your pocket.

A blueprint, not an app. It maps plan.jaybulb.com to four iPhone screens and one widget, so it can be built later without guessing. Nothing here is built.

Structure

Navigation

A TabView with four tabs, matching the web nav: Today, Plan, Money, Outlook. Each tab is a NavigationStack with a large title. Sources sit behind an info button on each screen, not in a tab.

Look

  • Same rules as the web: white and off-white surfaces, one accent #2F6FB0, seven flat chapter colours, no gradients or photos.
  • Square 2px corners on cards; only the app icon and the system tab bar round.
  • Standard system materials (tab bar, nav bar). Glass only where iOS puts it, never on content.
  • Dynamic Type, Dark Mode and Reduce Motion from day one.

Data

One JSON file

The app reads a plan.json served next to the page, so the web and the app never disagree. Cached offline; refreshed on launch.

Calendar

Classes and deadlines go straight into Calendar through EventKit, with one “Add to Calendar” prompt the first time. No .ics files on the page.

Scope

  • Read-only data from plan.json.
  • A local notification the day before each deadline.

Not now
